# Changelog

## v0.7.1 — изменения после v0.7.1-rc3

### Добавлено

- Клиенту добавлен транспорт `wss://`: TLS-коннектор выбирается по схеме DSN и
  принимает как CA-подписанные, так и самоподписанные сертификаты — доверие
  узлу обеспечивает ASTP-рукопожатие (X25519 + Ed25519), TLS остаётся
  камуфляжем. В ClientHello объявляются ALPN `h2` и `http/1.1`, как у
  настоящего браузера.
- Пример nginx-конфига для терминации `wss://` на белом IP
  (`contrib/config/nginx-wss-example.conf`) и документация по топологии
  «клиент → nginx (TLS + decoy-сайт) → anet_server по ws://»
  (`contrib/docs/wss.ru.md`).
- Экран Traffic (Statistics): карточки RX/TX/Total, SVG-график трафика за
  24 часа, таблицы по узлам и по пользователям.
- API активных соединений: кто подключён, к какой ноде, объём RX/TX и число
  соединений (`ActiveConnectionDto`).


### Изменено

- Полный визуальный рефакторинг WebUI: явная регистрация компонентов и
  директив Vuetify, кастомная тёмная тема (уголь с эмеральд-акцентом),
  filled-поля ввода, обновлённые шрифты и иконки.
- Переработаны модалки (пользователи, серверы, пулы, route maps) и экраны:
  Users и Servers переведены на `v-data-table` с серверной пагинацией,
  Statistics — на `v-tabs`/`v-tabs-window`, разметка очищена от сторонних
  UI-паттернов и сырых HTML-тегов.
- Схема БД: колонка `dsn` удалена из таблицы `servers` — адресация ноды
  снова собирается из `address` и портов транспорта; API создания, обновления
  и списка нод работает с полным набором атрибутов подключения.
- Route maps: убрана промежуточная таблица `user_route_maps`, пользователям
  назначается прямой FK `route_map_id` (ON DELETE SET NULL); логика
  применения карт упрощена.
- Генерация `client.toml`: блоки `[[servers]]` формируются по всем транспортам
  ноды в порядке failover (QUIC → WebSocket → SSH/VNC) с именами вида
  `Node [QUIC]`.
- Формы создания пользователя и сервера получили валидацию (UID, тариф),
  человекочитаемые названия в селектах и единый компонент формы профиля.

### Исправлено

- Дублирование сессий при переподключении клиента к панели.
- Генерация `client.toml` для нод, зарегистрированных по старой адресации
  (сборка DSN из legacy-полей).


## v0.7.0 — изменения после v0.6.3

### Добавлено

- Добавлен полноценный WebSocket-транспорт старающийся мимикрировать под реальный браузер.
- Для Windows реализована возможность выбирать, какие приложения ходят через туннель. 
- Добавлена фрагментация начального рукопожатия для противодействия сигнатурному
  DPI. Это привело к слому UDP (obfuscated QUIC), поэтому бамп v0.6 -> v0.7, сам протокол не сломан.


### Изменено

- Полностью переработана работа транспортов VNC, SSH, QUIC и WebSocket. Соединения стали быстрее, стабильнее и экономнее расходуют память. Это - вторая причина v0.6 -> v0.7.
- Улучшена маскировка трафика: пакеты получили случайные задержки, дополнение до разных размеров и более естественное поведение при передаче.
- Оптимизирована работа TUN-интерфейсов на Desktop и Android.
- Для QUIC добавлена возможность периодически отправлять ping, чтобы соединение не закрывалось при простое.
- Обновлён внешний вид Desktop GUI. Добавлены новые шрифты, иконки, панели управления и меню в системном трее.
- Клиент теперь запоминает активный сервер при автоматическом переключении между нодами.

### Исправлено

- Исправлены зависания при переподключении и остановке VPN.
- Исправлено завершение консольного клиента по нажатию `Ctrl+C`.
- Исправлены падения Android-приложения при переключении на SSH.
- Исправлено двойное закрытие TUN-интерфейса на Android.
- Исправлена очистка старого соединения перед подключением к следующему серверу.
- Повреждённые и слишком большие пакеты теперь отбрасываются без остановки туннеля.
