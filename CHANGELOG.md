# Changelog
##  — изменения после v0.7.2

### Добавлено
- **Web Admin Panel**
  - Показывает статистику траффика по серверам / пользователям.
  - Управление пользователями.
- **eBPF Traffic Shaper**
  - Ограничитель скорости работающий в пространстве ядра (собирается очень не скучно, за подробностями - в ридми, читать слоп от гемини).
- **Группы пользователей и пулы серверов**:
  - Реализована связка «Пользователь -> Группа Пользователей -> Пул серверов (Node pool)».
  - Поддержка кастомизации протоколов и точек входа (endpoints) для отдельных нод внутри пулов.
  - Добавлены метаданные групп серверов и алгоритмы взвешенного (weighted) выбора серверов для десктопных и мобильных клиентов.
  - В мобильных биндингах (Android) добавлена передача и обработка `AccountInfo` (тариф, ограничения, дата истечения подписки).
- **Транспорты и туннелирование**:
  - Добавлен AHTTP транспорт. (Вариация на тему xHTTPpacket up), проверено на Time Web CDN и CDNVideo - работает идеально. Для "не программисто это звучит как - "Обход белых Списков"
  - Для "не программисто это звучит как - "Обход белых Списков"
  - В REST API и интерфейс добавлены поля конфигурации `ahttp_url` для нод.
- **Управление сессиями и лимитами**:
  - Поддержка лимитов по количеству сессий и потребляемому трафику, с информированием клиентов об их исчерпании.
  - События тарифов (tariffs events) и обработка информации по ограничениям.
  - Реализована команда принудительного удалённого отключения сессии (`Disconnect`).
- **Клиенты (Десктоп и Мобайл)**:
  - Меню конфигурации и обновление UI/скриншотов в Android-приложении.
  - Совместимость с Android TV.
  - Возможность настройки исключений для адресов (Exclude addresses) и кнопка обновления в клиенте под Windows.
  - Полноценный режим работы в системном трее (Tray mode) и всплывающие системные уведомления.

### Изменено
- **Логика ядра клиентов**:
  - Переход на использование внутренних неизменяемых идентификаторов (Server ID / Group ID) для рабочей логики клиента, при этом для пользователей отображается человекочитаемое имя (Name).
  - Оптимизация производительности соединений и обработки внутренних состояний (state fix).
- **API и Бэкенд (anet-auth)**:
  - Масштабный рефакторинг HTTP API.
- **Инфраструктура**:
  - Обновлены примеры конфигурации балансировщика в `nginx.conf`.
  - Обновлены пайплайны CI/CD.

### Исправлено
- **Валидация адресов (REST API и WebUI)**:
  - Добавлена строгая проверка DSN, URL и адресов серверов при создании/обновлении нод в REST API. Полностью блокируется использование не-латинских (кириллических) символов, а также проверяются допустимые схемы (только `ws://`/`wss://` или `http://`/`https://`).
  - Аналогичная строгая валидация внедрена для URL-адресов членов пула (NodePoolMembers).
  - На фронтенде добавлены всплывающие предупреждения (алерты) с точным описанием ошибок валидации, приходящих от бэкенда.
- **Маршрутизация и Транспорты**:
  - Устранен критический баг «бесконечной петли» трафика при работе через CDN (возникал, когда при первом резолве выдавался один IP, а после коннекта CDN-узел резолвился по другому IP, из-за чего трафик уходил мимо реального узла).
  - Исправлен некорректный парсинг схемы `ws(s)` и портов по умолчанию.
  - Откачен экспериментальный коммит по автоматическому преобразованию IDN (Punycode) доменов в пользу более надежной строгой валидации (Drop of non-ASCII characters).
- **Прочие фиксы**:
  - Исправления сборки фронтенда (Vue build).
  - Исправления багов переподключения (reconnect fix) и работы VPN-туннеля в режиме «все приложения» на мобильных устройствах.
  - Решены проблемы с отображением статистики (по клику).
  - Мелкие правки обработчика аутентификации (`auth_handler`) и сброса счетчиков трафика.

## v0.7.2 — изменения после v0.7.1-rc3

### Добавлено

- Клиенту добавлен транспорт `wss://`: TLS-коннектор выбирается по схеме DSN и
  принимает как CA-подписанные, так и самоподписанные сертификаты — доверие
  узлу обеспечивает ASTP-рукопожатие (X25519 + Ed25519), TLS остаётся
  камуфляжем. В ClientHello объявляются ALPN `h2` и `http/1.1`, как у
  настоящего браузера.
- Пример nginx-конфига для терминации `wss://` на белом IP
  (`contrib/config/nginx-wss-example.conf`) и документация по топологии
  «клиент → nginx (TLS + decoy-сайт) → anet_server по ws://»
  (`contrib/docs/wss.ru.md`).
- Экран Traffic (Statistics): карточки RX/TX/Total, SVG-график трафика за
  24 часа, таблицы по узлам и по пользователям.
- API активных соединений: кто подключён, к какой ноде, объём RX/TX и число
  соединений (`ActiveConnectionDto`).


### Изменено

- Полный визуальный рефакторинг WebUI: явная регистрация компонентов и
  директив Vuetify, кастомная тёмная тема (уголь с эмеральд-акцентом),
  filled-поля ввода, обновлённые шрифты и иконки.
- Переработаны модалки (пользователи, серверы, пулы, route maps) и экраны:
  Users и Servers переведены на `v-data-table` с серверной пагинацией,
  Statistics — на `v-tabs`/`v-tabs-window`, разметка очищена от сторонних
  UI-паттернов и сырых HTML-тегов.
- Схема БД: колонка `dsn` удалена из таблицы `servers` — адресация ноды
  снова собирается из `address` и портов транспорта; API создания, обновления
  и списка нод работает с полным набором атрибутов подключения.
- Route maps: убрана промежуточная таблица `user_route_maps`, пользователям
  назначается прямой FK `route_map_id` (ON DELETE SET NULL); логика
  применения карт упрощена.
- Генерация `client.toml`: блоки `[[servers]]` формируются по всем транспортам
  ноды в порядке failover (QUIC → WebSocket → SSH/VNC) с именами вида
  `Node [QUIC]`.
- Формы создания пользователя и сервера получили валидацию (UID, тариф),
  человекочитаемые названия в селектах и единый компонент формы профиля.

### Исправлено

- Дублирование сессий при переподключении клиента к панели.
- Генерация `client.toml` для нод, зарегистрированных по старой адресации
  (сборка DSN из legacy-полей).


## v0.7.0 — изменения после v0.6.3

### Добавлено

- Добавлен полноценный WebSocket-транспорт старающийся мимикрировать под реальный браузер.
- Для Windows реализована возможность выбирать, какие приложения ходят через туннель. 
- Добавлена фрагментация начального рукопожатия для противодействия сигнатурному
  DPI. Это привело к слому UDP (obfuscated QUIC), поэтому бамп v0.6 -> v0.7, сам протокол не сломан.


### Изменено

- Полностью переработана работа транспортов VNC, SSH, QUIC и WebSocket. Соединения стали быстрее, стабильнее и экономнее расходуют память. Это - вторая причина v0.6 -> v0.7.
- Улучшена маскировка трафика: пакеты получили случайные задержки, дополнение до разных размеров и более естественное поведение при передаче.
- Оптимизирована работа TUN-интерфейсов на Desktop и Android.
- Для QUIC добавлена возможность периодически отправлять ping, чтобы соединение не закрывалось при простое.
- Обновлён внешний вид Desktop GUI. Добавлены новые шрифты, иконки, панели управления и меню в системном трее.
- Клиент теперь запоминает активный сервер при автоматическом переключении между нодами.

### Исправлено

- Исправлены зависания при переподключении и остановке VPN.
- Исправлено завершение консольного клиента по нажатию `Ctrl+C`.
- Исправлены падения Android-приложения при переключении на SSH.
- Исправлено двойное закрытие TUN-интерфейса на Android.
- Исправлена очистка старого соединения перед подключением к следующему серверу.
- Повреждённые и слишком большие пакеты теперь отбрасываются без остановки туннеля.
