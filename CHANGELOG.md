# Changelog

## v0.7.0 — изменения после v0.6.3

### Добавлено

- Добавлен полноценный WebSocket-транспорт старающийся мимикрировать под реальный браузер.
- Для Windows реализована возможность выбирать, какие приложения ходят через туннель. 
- Добавлена фрагментация начального рукопожатия для противодействия сигнатурному
  DPI. Это привело к слому UDP (obfuscated QUIC), поэтому бамп v0.6 -> v0.7, сам протокол не сломан.


### Изменено

- Полностью переработана работа транспортов VNC, SSH, QUIC и WebSocket. Соединения стали быстрее, стабильнее и экономнее расходуют память. Это - вторая причина v0.6 -> v0.7.
- Улучшена маскировка трафика: пакеты получили случайные задержки, дополнение до разных размеров и более естественное поведение при передаче.
- Оптимизирована работа TUN-интерфейсов на Desktop и Android.
- Для QUIC добавлена возможность периодически отправлять ping, чтобы соединение не закрывалось при простое.
- Обновлён внешний вид Desktop GUI. Добавлены новые шрифты, иконки, панели управления и меню в системном трее.
- Клиент теперь запоминает активный сервер при автоматическом переключении между нодами.

### Исправлено

- Исправлены зависания при переподключении и остановке VPN.
- Исправлено завершение консольного клиента по нажатию `Ctrl+C`.
- Исправлены падения Android-приложения при переключении на SSH.
- Исправлено двойное закрытие TUN-интерфейса на Android.
- Исправлена очистка старого соединения перед подключением к следующему серверу.
- Повреждённые и слишком большие пакеты теперь отбрасываются без остановки туннеля.
